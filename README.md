# FullStack Todo App

![.NET 8](https://img.shields.io/badge/.NET-8.0-5C2D91?logo=.net&logoColor=white)

Tamamen sıfırdan yapılmış, gerçek bir **full-stack** Todo uygulaması.

## Özellikler
- .NET 8 Minimal API + Entity Framework Core + SQLite
- React 18 + Vite + Axios + Bootstrap 5
- CRUD işlemleri (Ekle / Tamamla / Sil)
- CORS ayarlı, production-ready
- Tek repo’da hem backend hem frontend
